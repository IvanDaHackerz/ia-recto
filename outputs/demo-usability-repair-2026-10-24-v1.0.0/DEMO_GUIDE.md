# Demo rehearsal

From the VS Code terminal in `C:\IA`, run `./start-website.ps1`. Open the URL printed by the launcher; it can select another free port when one is occupied. Enable **Use AI explanations**. Leave saving off for fictional demo questions. Together.ai must be configured for the same Windows account, with working internet and sufficient provider credit.

Show these flows:

1. **One labor concern:** a private employer missing salary dates; ordinary overtime; probation standards; dismissal procedure.
2. **One consumer concern:** a retailer's warranty role; charging above a price tag; wrong online delivery; poor paid-service quality; cash change.
3. **Two supported concerns:** delayed private wages plus a separate defective retail purchase. Check that both appear and that each explanation has its own references.
4. **Partly supported:** private overtime plus a separate bank-account fee. Show the supported explanation and the separate scope boundary.
5. **Outside scope:** overseas employment, government employment, privacy-only, banking, criminal charges or predicting a case outcome. A scope explanation/referral is the expected behavior.
6. **AI off:** submit a complete question, inspect classification and retrieved provisions, then enable AI and submit again to compare the workflows.
7. **References and performance:** open a cited provision, inspect its stored wording, then show the recorded performance page and its synthetic-development provenance.

Use full fictional concerns on every submission. The page evaluates each submission independently. If it asks for a missing fact, use **Edit this question** and include that fact in the full question. Confidence is label certainty, not an accuracy score for an unlabeled question.

The system should explain a directly supported recorded rule, ask a focused clarification where needed, or clearly state its source/scope limitation. Do not present every refusal or source gap as a classifier failure, and do not present an automatically checked paragraph as independent legal verification.

Known coverage limits still include held counted-working-time/meal-period authorities, unsupported final-pay/COE deadlines, missing related thirteenth-month authority, exact current regional wage amounts and source-currentness review. The prototype may show a limited source response or withhold AI prose for these requests.
